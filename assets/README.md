# PokeNavis Assets

Only add **originally created or properly licensed** placeholder sprites, tilesets, UI artwork and audio. Maintain attribution and licence information for each third-party asset. Do not add Pokémon game ROMs, extracted sprites, music, copyrighted map exports or other uncleared protected assets.

Recommended organization when assets exist:

```text
assets/
  sprites/
  tilesets/
  audio/
  ui/
  licenses/
```

The visual direction is Gen 5-inspired **2D pixel art**, not a commitment to use protected sprites or maps.
